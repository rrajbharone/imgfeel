## File Format Guide: Which Format Works Best for 200KB?

Selecting the appropriate output format ensures maximum image quality at 200 KB:

### 1. JPG / JPEG (Best for Colored Certificates & Photographs)
- **Ideal For**: Academic degrees, colored marksheet scans, passport portraits, and job application forms.
- **Why It Works**: JPG's discrete cosine transform compression provides rich color gradients and realistic skin tones under 200 KB.

### 2. PNG (Best for Line Art, Stamps & Signatures)
- **Ideal For**: Official stamps, digital signatures, vector icons, and transparent background graphics.
- **Why It Works**: Lossless Deflate encoding keeps high-contrast pen strokes perfectly sharp with zero ringing artifacts around letters.

### 3. WebP (Best for Modern Web & Mobile UI)
- **Ideal For**: Web hero banners, blog graphics, user profiles, and e-commerce thumbnails.
- **Why It Works**: Modern predictive encoding delivers up to 35% higher visual density than JPEG at equivalent 200 KB file weights.
